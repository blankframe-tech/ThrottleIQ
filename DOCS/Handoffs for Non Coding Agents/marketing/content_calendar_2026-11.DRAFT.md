**Rules for every post**
- Bangla first. All Bangla is **machine-drafted and needs a native read (#23)**; the EN
  line under each post is a gist for the reviewer, not a second post.
- Link in the **first comment**, never in the post body (FB groups throttle link posts).
- Every link is the install page with the post's code:
  `https://www.blankframe.tech/throttle-iq/install/?c=<code>` (the T1 flow: join the
  tester group → accept the test → install from Play). Never the raw Play link.
- **No crash-alert promises.** No "the app will tell your family if you fall", no SOS,
  no automatic alerts. Crash detection is shadow mode and sends nothing. Live Share is a
  link the rider starts by hand; say exactly that.
- No prices, fines or legal details from memory. Where a post needs one, it says
  "check the official notice" or uses the rider's own numbers from the app.
- 3–9 Nov: owner away, **nothing posted** (no replies expected either).

**Metric to check** for every post, 48 h after: comments and shares on the post, and
