# Contributor t-shirts: printing cost (task for a non-coding agent)

Work out what it costs to print the contributor tees. Nothing is ordered yet.

## The designs

`DOCS/General/partnerships/for_contributors/` (spec and print sizes in its `README.md`).
Designs 1–15. `design/` holds each mockup and the print-ready `_artwork.svg`; `realistic/` holds photo-style previews.
All are oversized drop-shoulder tees, 260–280 GSM cotton, most with a front chest print and a large back print.

## Price sources

1. **Customizely product designer** (upload the art, read the price per tee):
   https://customizely.net/customizely-product-designer/?product_base=19&product_cms=11704
2. **Dhaka DTF, drop-shoulder t-shirt, MOQ 50 pcs**:
   https://www.dhakadtf.com/products/dropshoulder-t-shirt-moq-50-pcs?variant=50910114414914

## What to report

For each source, in BDT:

- Price per blank tee, and per print (front chest, back print). Note the size and colour limits.
- Total per tee for one front + one back print, at 1, 10, 25 and 50 pcs (Dhaka DTF needs 50 minimum).
- Delivery cost and time to Dhaka.
- Whether the shirt colours we use are available (black, charcoal, grey, olive, sand; see each design's colorway).
- Design 15 uses metallic gold ink and design 11 prints a different number per person: say whether each source can do that, and the extra cost.

Finish with a recommendation: which source for a first run of about 25 tees, and the total. Write the date you read the prices: they change.
