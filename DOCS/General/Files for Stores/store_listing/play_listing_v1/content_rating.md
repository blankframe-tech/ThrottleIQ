# Content rating answers (IARC questionnaire) — 2026-11-01

Play Console → Policy → App content → Content ratings. Google's help pages
(https://support.google.com/googleplay/android-developer/answer/9859655, fetched
2026-11-01) don't list the questions, so the topics below follow the usual IARC
questionnaire; **the exact question wording is unverified**. Answer what the app does
today, not plans.

**Category:** pick the non-game category ("Utility, Productivity, Communication or
Other" or the closest one shown). ThrottleIQ is not a game.

| Topic | Answer | Why (what the app does) |
|---|---|---|
| Violence, blood, gore | No | No such content |
| Sexuality, nudity | No | None |
| Profanity / crude humour | No (app content) | Forum text is user-written; covered by the user-interaction answers below, not here |
| Drugs, alcohol, tobacco | No | None |
| Gambling / simulated gambling | No | No betting, no prizes |
| Fear / horror | No | None |
| Users can interact or exchange content | **Yes** | Forums, ride comments, follows, place reviews |
| User-generated content can be shared | **Yes** | Ride posts with photos, forum photos (up to 4) |
| Shares the user's location with other users | **Yes** | Live Share link (rider starts it, 24 h), group ride map, shared routes (start/end trimmed) |
| Digital purchases | No | The app is free with no in-app purchases |
| Unrestricted web browser / search engine | No | |
| Ads | No | Matches App content → Ads: No |

Expect a rating above the lowest tier because of user interaction and location sharing
(`data_safety_and_permissions.md`, last section). Target audience stays **18+**
(`app_content_remaining.md`). Moderation and reporting exist in the forums
(`../../moderation_policy.md`), which helps if Google asks how UGC is handled.

Do not tick anything about crash detection or emergency features: it is shadow mode,
off for riders, and sends nothing.
