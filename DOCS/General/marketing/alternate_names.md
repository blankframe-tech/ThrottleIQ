# Alternate names for ThrottleIQ

Working list from a naming brainstorm, 2026-09-11. Not a decision doc — just
candidates with the angle each one plays, so a shortlist can get picked later.

## Proposed (yours)

| Name | Angle |
|---|---|
| TorqueTrace | Ride-logging/track framing — "trace" = the recorded path/data |
| Kickstand | Everyday moto word, approachable, doesn't oversell the tech |
| RevBook / TorqueBook | Logbook framing for ride history + maintenance tracking |
| TrueRev | Honesty/accuracy framing — "true" telemetry vs. guesswork |
| MotoSight | Vision/awareness framing — situational awareness, hazard sensing |
| PowerBand | The RPM sweet spot on a rev range — doubles as a two-stroke term (below) |
| MindfulMoto | Calm/safety framing — pairs well with the anxious-family segment |
| RideIQ | Closest direct swap for ThrottleIQ, keeps the "IQ" equity |

## Two-stroke specific

Two-strokes (RX100, RD, older commuter bikes) have real nostalgia in the
Bangladesh enthusiast segment, so these lean into their specific culture and
mechanics rather than generic "motorcycle":

| Name | Angle |
|---|---|
| Ring-Ding | Nickname riders use for the distinctive two-stroke exhaust note |
| Blue Smoke | The signature two-stroke exhaust characteristic |
| Premix | The fuel-oil premix a two-stroke runs on — insider term |
| Expansion Chamber | The tuned exhaust pipe that defines two-stroke performance |
| PowerBand | (see above) — the narrow, explosive power delivery two-strokes are known for |
| TwoSmoke | Blunt, plays the "two-stroke" pun straight |

## 10 more I like

| Name | Angle |
|---|---|
| Redline IQ | Closest swap for ThrottleIQ — keeps "IQ" equity, tachometer cue instead of throttle |
| Vector / RideVector | Nods to the state-vector/IMU-fusion architecture without sounding jargon-y |
| Guardian Rev | Combines family-safety framing with the rev pun — my top pick from the safety angle |
| BlackBox Moto / FlightBox Moto | Leans into the "flight recorder for your bike" pitch you already use in marketing copy |
| CrashLog | Blunt, but instantly communicates the crash-detection feature |
| Pulse Rider / RidePulse | Heartbeat/telemetry framing, softer tone for the family-safety segment |
| Odomind | Odometer + mind — "smart" angle without reusing "IQ" |
| Throttlebook | Logbook framing, close cousin of RevBook/TorqueBook above |
| Chapa Sathi | "Throttle companion" in Bangla — warm, local, fits the community-crew segment |
| Moto Nojor | "Watchful eye" in Bangla — pairs naturally with the safety pitch |

## Notes

- **RevIQ** was floated as a tighter version of "Ideal Rev" (rejected — read
  as a fitness/tuning app name, lost the telemetry signal, and `idealrev` as
  one word/domain risks misreading as "idea-lrev").
- If testing one against ThrottleIQ head-to-head: **Guardian Rev** for the
  safety/family pitch, **Redline IQ** if you want the safest, most
  recognizable swap.
