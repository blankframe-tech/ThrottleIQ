# ThrottleIQ — Screen Walkthrough (Carbon Mono skin)

40 screenshots captured from the iOS Simulator (iPhone 17, iOS 26.5), numbered in
the order you'd want to walk someone new through the app.

The **Carbon Mono** skin (the app default): dark, sharp, instrument-panel.
The same 40 screens in the **Trail Social** skin are in [`../trail_social/`](../trail_social/).
