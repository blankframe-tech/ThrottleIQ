# Outreach templates — Phase 0 / Phase 1

Ready-to-send drafts for the channel plan in `marketing.md` §5. Each is
written to be copy-pasted and lightly personalized (fill the bracketed
parts), not sent verbatim to hundreds of people — these communities are
close-knit and ad-skeptical (`marketing.md` §5), so a templated-feeling
mass post will read exactly as what it is.

**Sequencing reminder:** none of the Phase 1 templates should go out until
the Play Console tester-list blocker (`NEEDS_YOUR_ATTENTION.md` #1) is
closed — there has to be a build people can actually install when they
respond.

## 6. First-launch "how did you hear about us" — product spec, not copy

Not outreach copy, but belongs here since it's what makes all the above
measurable. `marketing.md` §7 calls for a single optional field on first
launch. Suggested implementation (for whoever picks this up — not
implemented this session, since it touches onboarding/first-run app code
that's out of a marketing pass's scope to change unreviewed):

- One optional single-select shown once, after first sign-in, never
  blocking: "How did you hear about ThrottleIQ?" — options: Facebook group,
  friend/rider referral, YouTube/reel review, touring club, garage/shop
  sign, other (free text), prefer not to say.
- Store as a plain field on the user's profile doc (`referralSource`), not
  a separate analytics event pipeline — this app doesn't have one yet and
  building one just for this is overkill for a single field.
- Report on it by grouping installs from Play Console's own cohort data
  against this field manually for now (weekly, per `marketing.md` §7) —
  no dashboard needed yet at this volume.
