# Root Directory

This directory contains components related to `root`.

## Submodules

This directory contains the following submodules:

- **[app](./app)**: The root directory of the Flutter application.
- **[designs](./designs)**: Contains UI/UX designs, SVGs, and branding assets.
- **[docs](./docs)**: Contains additional documentation and markdown files.
- **[functions](./functions)**: Contains Firebase Cloud Functions backend code.
- **[public](./public)**: Contains public static assets for Firebase Hosting.
- **[store_listing](./store_listing)**: Components and logic related to store_listing.
