# Core Directory

Contains core application infrastructure, services, theme definitions, and utilities shared across the app.

## Submodules

This directory contains the following submodules:

- **[analytics](./analytics)**: Analytics service tests.
- **[cloud](./cloud)**: Cloud repository, outbox, track codec and maintenance-settings sync tests.
- **[i18n](./i18n)**: Localization tests (ARB parity, generated lookups, locale provider).
- **[router](./router)**: Components and logic related to router.
- **[utils](./utils)**: Contains helper functions, constants, and extensions specific to this layer.
