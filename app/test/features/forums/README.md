# Forums Directory

Community forums feature for discussions.

## Files

The following files are present in this directory:

- `forum_entity_test.dart`: Unit/Widget test file.
- `forum_permissions_test.dart`: Unit/Widget test file.
- `forum_post_entity_test.dart`: Unit/Widget test file.
- `forum_reply_entity_test.dart`: Unit/Widget test file.
- `forum_repository_test.dart`: Unit/Widget test file.
- `garage_forums_test.dart`: Unit/Widget test file.
- `forum_post_model_test.dart`: Pit Wall post fields (type, solved, bike, attachment) serialization and legacy-doc defaults.
- `forum_solution_test.dart`: mark-solved / accept-solution toggles and solution-first reply order.
- `forum_pulse_test.dart`: Pulse source selection, filter chips, page merge, directory ids.
- `forum_bookmarks_test.dart`: local saved-post encoding and toggling.
- `forum_author_bike_test.dart`: byline bike badge and odometer formatting.
- `forums_pulse_view_test.dart` / `forums_hubs_view_test.dart`: widget tests for the two Forums lenses.
