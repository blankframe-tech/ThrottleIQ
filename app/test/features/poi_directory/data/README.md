# Data Directory

Data layer handling external data sources, APIs, local storage, and repository implementations.

## Submodules

This directory contains the following submodules:

- **[repositories](./repositories)**: Contains data repository implementations for fetching, syncing, and persisting data (e.g., Firestore, SQLite).
- **[services](./services)**: Contains external service integrations (e.g., APIs, platform channels, device sensors).
- **[utils](./utils)**: Contains helper functions, constants, and extensions specific to this layer.
