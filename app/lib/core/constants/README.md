# Constants Directory

This directory contains components related to `constants`.

## Files

The following files are present in this directory:

- `app_dimensions.dart`: Dart source code.
- `bike_catalog.dart`: Curated Bangladesh-market brand → model list for bike autocomplete.
- `bike_colors.dart`: Preset bike paint colors for the color picker.
- `motorcycle_quotes.dart`: Dart source code.
- `sensor_constants.dart`: Dart source code.

Colors are no longer constants here: design tokens live on the theme (`core/theme/`, read via `context.palette`).
