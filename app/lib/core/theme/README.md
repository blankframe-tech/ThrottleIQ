# Theme Directory

This directory contains components related to `theme`.

## Files

The following files are present in this directory:

- `app_shape_profile.dart`: Shape tokens (`AppShapeProfile` theme extension; one profile, `curvy`).
- `app_theme.dart`: Dart source code.
- `app_theme_context.dart`: `context.palette` / `context.shape` accessors for the active design tokens.
- `app_theme_style.dart`: The two palettes (`calmingLight`, `carbonMonoDark`) as the `AppColorPalette` theme extension.
- `app_typography.dart`: Display typeface and live-ride cockpit type styles.
- `theme_style_provider.dart`: Persists the rider's System / Dark / Light choice, and migrates picks of removed themes.
