# Services Directory

Contains external service integrations (e.g., APIs, platform channels, device sensors).

## Files

The following files are present in this directory:

- `auto_tracking_service.dart`: Foreground-service isolate for auto ride detection.
- `battery_service.dart`: Dart source code.
- `bug_report_service.dart`: Collects a minimal diagnostic bundle and shares it via the native share sheet.
- `cloudinary_upload_service.dart`: Dart source code.
- `haptic_service.dart`: Dart source code.
- `home_widget_service.dart`: Feeds data to the native home-screen widgets.
- `notification_service.dart`: Local notifications (crash escalation, ride-confirmation prompts, weekly digest).
- `weather_service.dart`: Ride-start weather from Open-Meteo (free, keyless).
