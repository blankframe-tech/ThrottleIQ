# Screens Directory

Contains Flutter UI screen widgets for this feature. These are the main views presented to the user.

## Files

The following files are present in this directory:

- `login_screen.dart`: Flutter screen widget.
- `onboarding_manifest.dart`: Single source of truth for the feature-tour steps.
- `onboarding_screen.dart`: Flutter screen widget.
- `onboarding_tour_provider.dart`: Riverpod provider for onboarding-tour progress/completion.
- `register_screen.dart`: Flutter screen widget.
- `splash_screen.dart`: Flutter screen widget.
