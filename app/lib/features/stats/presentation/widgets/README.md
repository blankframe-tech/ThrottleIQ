# Widgets Directory

Contains reusable Flutter UI components specifically for this feature.

## Files

The following files are present in this directory:

- `badge_detail_sheet.dart`: Single-badge sheet: art, earned date or progress, share.
- `badge_grid.dart`: Dart source code.
- `ride_line_chart.dart`: Dart source code.
- `ride_route_thumbnail.dart`: Dart source code.
- `year_review_card.dart`: The one-page year summary card (the story's last page) and its month bars.
- `year_story_slides.dart`: The year-in-review story pages, each a fixed 360x640 canvas exported at 1080x1920.
