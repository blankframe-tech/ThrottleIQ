# Providers Directory

Contains Riverpod state management providers and notifiers for this feature. These manage state and bind data to the UI.

## Files

The following files are present in this directory:

- `badge_rarity_provider.dart`: Reads the `stats/badges` aggregate (badge ownership %) and replays local rides for badge earned dates.
- `badge_sync_provider.dart`: Riverpod provider definition.
- `ride_polyline_provider.dart`: Riverpod provider definition.
- `rider_stats_provider.dart`: Riverpod provider definition.
