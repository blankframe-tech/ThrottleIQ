# Calculators Directory

Contains domain-specific calculators and algorithms (e.g., fuel efficiency, distance).

## Files

The following files are present in this directory:

- `accel_axis_calibrator.dart`: Dart source code.
- `auto_ride_reconciler.dart`: Dart source code.
- `average_speed.dart`: Dart source code.
- `daily_ride_summary.dart`: Dart source code. Auto-tracking end-of-day summary: merges jam-split detections (20-min gap) and counts them with recorded rides.
- `elevation_profile.dart`: Dart source code.
- `event_detector.dart`: Dart source code.
- `final_ride_stats.dart`: Dart source code.
- `impact_detector.dart`: Dart source code.
- `jam_time.dart`: Dart source code.
- `motion_calculator.dart`: Dart source code.
- `recording_cadence_policy.dart`: Dart source code.
- `ride_resume.dart`: Dart source code.
- `segment_speed_aggregator.dart`: Dart source code.
- `sensor_validator.dart`: Dart source code.
- `speed_baseline.dart`: Dart source code.
- `speed_segments.dart`: Dart source code.
- `vehicle_state_estimator.dart`: Dart source code.
