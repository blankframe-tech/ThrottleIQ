# Providers Directory

Contains Riverpod state management providers and notifiers for this feature. These manage state and bind data to the UI.

## Submodules

This directory contains the following submodules:

- **[helpers](./helpers)**: Coordinators split out of the recording notifier (sensor fusion, crash, live session, persistence).

## Files

The following files are present in this directory:

- `auto_tracking_provider.dart`: Riverpod provider definition.
- `live_ride_places_provider.dart`: Riverpod provider definition.
- `ride_recording_provider.dart`: Riverpod provider definition.
- `ride_repository_provider.dart`: Riverpod provider definition.
