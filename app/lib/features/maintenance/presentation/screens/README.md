# Screens Directory

Contains Flutter UI screen widgets for this feature. These are the main views presented to the user.

## Files

The following files are present in this directory:

- `maintenance_screen.dart`: The maintenance page (hero, forecast strip, checks by urgency, quick check, visits, money, papers, settings).
- `add_maintenance_log_screen.dart`: "Log a visit" — log or edit a whole service visit.
- `maintenance_setup_screen.dart`: Per-bike setup (schedule, roads, oil grade, last oil change).
- `check_detail_screen.dart`: One tracked check up close.
- `maintenance_config_screen.dart`: Customize which checks are tracked, including your own.
