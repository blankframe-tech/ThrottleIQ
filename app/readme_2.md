# App Directory

The root directory of the Flutter application.

## Submodules

This directory contains the following submodules:

- **[android](./android)**: Components and logic related to android.
- **[assets](./assets)**: Components and logic related to assets.
- **[build](./build)**: Components and logic related to build.
- **[ios](./ios)**: Components and logic related to ios.
- **[lib](./lib)**: The main source code directory of the Flutter application.
- **[scripts](./scripts)**: Components and logic related to scripts.
- **[test](./test)**: Contains unit, widget, and integration tests for the application.

## Files

The following files are present in this directory:

- `SETUP.md`: Markdown document.
- `analysis_options.yaml`: Configuration file.
- `firestore_rules_poi_directory.txt`: Source file.
- `pubspec.yaml`: Configuration file.
